## Add the package

Xcode: File › Add Package Dependencies › Add Local…, choose this folder, add the library `SebaroDesign` to the app target. Or in another package:

```swift
.package(path: "<path>/SebaroDesign"),
.target(name: "<App>", dependencies: [.product(name: "SebaroDesign", package: "SebaroDesign")])
```

## Use

```swift
import SebaroDesign
import SwiftUI

@main
struct MyApp: App {
    @State private var ready = false
    var body: some Scene {
        WindowGroup {
            SebaroAppRoot {
                SbStart(product: .tagwerk, ready: ready) { ContentView() }
            }
            .task { /* load */ ready = true }
        }
    }
}
```

`SebaroAppRoot` registers the fonts, applies Hell/Dunkel (`sb-theme`), the colour tone (`sb-tone`) and „Bewegung immer reduzieren“ (`sb-motion`) and installs the navigation bar appearance. Read colours only through `Color.sb*` and the environment's `sebaroTone` (`tone.bg`, `tone.text` …); never hex literals. Use `.sbFont(_:)` for text: it draws the exact weights (400/430, 570/600, 670/700), which the generated `.sbTextStyle(_:)` cannot.

Rules and recipes: `systems/sebaro/AGENTS.md` and `spec/12-platform-ios.md` in sebaroDesign. The package was built and its tests run there against the iOS simulator (spec/12 §12); it was not run on a device, and VoiceOver was not tried.

## Keep in sync

```sh
python3 <sebaroDesign>/tools/export_system.py sebaro --target ios --out <this directory> --exclude-products <private exclusion list>
python3 <sebaroDesign>/tools/export_system.py --verify <this directory> --exclude-products <private exclusion list>
python3 export_system.py --verify <this directory> --files-only    # CI without a sebaroDesign checkout
```

`--verify` exits 1 when a file here was edited or deleted, when its source in sebaroDesign changed, when a fresh export would add or drop files, or when a gate of the system fails; it needs a sebaroDesign checkout. `--files-only` needs only `export_system.py` and this folder: it catches edits and deletions here, **not** source drift. Re-export to update.
