Rust
let a = load_appearance(app);
let dark = is_dark(&a, a.last_dark);
let ground = SEBARO_BG[(a.tone == Tone::Warm) as usize][dark as usize];
WebviewWindowBuilder::new(app, "main", url)
    .background_color(Color(ground.0, ground.1, ground.2, 255))
    .theme(Some(if dark { Theme::Dark } else { Theme::Light }))

Die Wahl steht in der eigenen Einstellungsdatei der App (oben die Datei appearance; eine App, die schon eine Einstellungsdatei hat, nimmt diese), der Farbton als „cool“ oder „warm“. SEBARO_BG schreibt build.rs beim Bauen aus dem exportierten tokens.json unter SEBARO_EXPORT: kühl und warm, hell und dunkel. Ein Skript vor denen der Seite schreibt sb-theme für theme-init.js, sb-tone nur bei „warm“.

Das Fenster entsteht in Rust, im Grund der gespeicherten Wahl (Hell oder Dunkel, Kühl oder Warm), und die Seite bekommt die Wahl vor ihren Skripten. So öffnet ein dunkles Fenster ohne weißen Blitz. Ändert die Seite die Wahl, setzt set_appearance Grund und Thema jedes Fensters.
